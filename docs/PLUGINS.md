# Система плагинов VGRAM

## Текущее состояние

В VGRAM добавлен реестр встроенных плагинов, экран управления и сохранение переключателей. Настройки доступны в приложении: **Настройки → Оформление VGRAM → Плагины VGRAM**.

Сейчас зарегистрированы:

| ID | Название | Что контролирует | По умолчанию |
| --- | --- | --- | --- |
| `liquid_glass` | Жидкое стекло | Флаг Liquid Glass в поддерживаемых элементах интерфейса | Включён |
| `profile_badges` | Бейджи профиля | Отображение бейджей рядом с именем в профиле | Включён |

Настройки сохраняются локально в SharedPreferences, в файле настроек `vgram_plugins`. Состояние переживает перезапуск приложения.

## Важное ограничение безопасности

Это система **встроенных плагинов**: код модулей компилируется вместе с VGRAM. Текущая версия не скачивает и не запускает сторонние APK, JAR, DEX или скрипты. Это намеренное ограничение: произвольный код из интернета мог бы получить доступ к сообщениям, файлам или учётным данным.

## Как добавить встроенный плагин

1. Создайте класс в пакете `org.telegram.ui`, реализующий `VgramPlugin`.
2. Верните стабильный уникальный ID, название, описание и состояние по умолчанию.
3. Зарегистрируйте экземпляр в статическом списке `VgramPluginManager`.
4. Перед выполнением поведения модуль должен проверить `VgramPluginManager.isEnabled(context, "your_plugin_id")`.
5. Если модулю нужны побочные эффекты при включении/выключении, добавьте их в `VgramPluginManager.setEnabled(...)` или в отдельный контролируемый обработчик.
6. Соберите приложение и проверьте оба состояния, повторный запуск и работу без сети.

Пример класса:

```java
package org.telegram.ui;

public final class ExampleVgramPlugin implements VgramPlugin {
    @Override public String getId() {
        return "example_plugin";
    }

    @Override public String getName() {
        return "Пример плагина";
    }

    @Override public String getDescription() {
        return "Описание возможностей плагина.";
    }

    @Override public boolean isEnabledByDefault() {
        return false;
    }
}
```

В реестре добавьте `new ExampleVgramPlugin()`. В коде, который выполняет функцию плагина, проверяйте флаг:

```java
if (VgramPluginManager.isEnabled(context, "example_plugin")) {
    // Выполнять только функциональность этого модуля.
}
```

## Правила для новых модулей

- Не храните токены, пароли, ключи администратора или приватные данные в исходном коде приложения.
- Не обходите ограничения Telegram и не отправляйте данные пользователя без явного действия и понятного объяснения.
- Используйте уникальные постоянные ID; не переиспользуйте ID удалённого плагина для другой функции.
- Любые сетевые запросы выполняйте вне главного UI-потока, с таймаутами и обработкой ошибок.
- Не загружайте и не исполняйте код, полученный с сервера.
- Плагин должен корректно работать, если он выключен, сервер недоступен или его настройки ещё не созданы.

## Файлы реализации

- `VgramPlugin.java` — контракт встроенного плагина.
- `VgramPluginManager.java` — реестр, хранение состояния и обработка переключателя Liquid Glass.
- `VgramPluginsActivity.java` — экран управления.
- `VgramAppearanceActivity.java` — переход к экрану плагинов.
- `ProfileActivity.java` — проверка флага для бейджей профиля.
